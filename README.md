# SMC Trading Dashboard — Prototype

Ready for Streamlit Community Cloud. The UI prototypes the supplied backend's major workflow: multi-base demand/supply zones, candle classification, BOS, sweeps, order blocks, swing points, trade-score/confluence, backtesting, performance metrics, and sequential risk management.

The current backend is intentionally a UI-safe prototype. Your supplied backend should be integrated incrementally through `data_access.py`.

Entry point: `app.py`
